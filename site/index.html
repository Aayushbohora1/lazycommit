Why

Writing good commit messages is busywork. lazycommit reads your staged diff, picks a conventional-commit type from the filenames and content, and prints a one-liner in <100ms. Edit it if you care. Ship it if you don't.

Two modes

Heuristic (free) — runs offline, zero deps, no telemetry. Good enough for most diffs.

AI (paid) — calls Claude via our hosted API. Higher-quality subjects and a body line when the diff is non-trivial. 5 free generations/day per IP, then $5/mo unlimited.

Install

npm i -g lazycommit

Usage

lazycommit           # print a conventional commit message
lazycommit -c        # print and `git commit -m` it
lazycommit --ai      # use hosted AI (set LAZYCOMMIT_API_KEY)
lazycommit --dry     # preview only
